# Agenda do Síndico Brasil

Feiras, congressos e encontros para síndicos, administradoras e incorporadoras em todo o Brasil, com datas, preços e links de inscrição.

Portal: https://thbarbosas.github.io/AgendaDoSindicoBrasil/

- `index.html`: o portal (mapa, gráficos, filtros e agenda).
- `eventos.json`: os eventos. Atualizado automaticamente duas vezes ao dia.
- `mapa.json`: contornos dos estados para o mapa.
